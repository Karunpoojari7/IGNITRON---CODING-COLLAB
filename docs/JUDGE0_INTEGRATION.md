# Judge0 Sandboxed Execution Engine Integration

## Overview
Submissions in Round 3 (Final) are executed against pre-configured public and hidden test cases using Judge0 API.

## Limits & Constraints
- **Maximum Execution Time:** 2.000 seconds per test case.
- **Maximum Memory Allocation:** 128 MB (131072 KB).
- **Supported Languages:**
  - Python 3 (Language ID 71)
  - Java OpenJDK 17 (Language ID 62)
  - C++ GCC 9.2 (Language ID 54)
  - JavaScript Node.js 18 (Language ID 63)

## Status Mapping
- `3` : Accepted (AC)
- `4` : Wrong Answer (WA)
- `5` : Time Limit Exceeded (TLE)
- `6` : Compilation Error (CE)
- `11`: Runtime Error (NZEC)
